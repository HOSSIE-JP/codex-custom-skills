# AI Character Reference Reconstructor

1枚以上のキャラクター参照画像から、AIで再利用しやすい分離型キャラクターリファレンスを作成するスキルです。

## 出力

- 第1画像: 全身四方向ビューシート
- 第2画像: 頭部六方向ビューシート
- 第3画像: 厳選六表情シート
- 第4画像: 必要な場合のみ固有パーツ詳細シート
- English Prompt Tag Dictionary
- Integrated Tag String

画像は必ず別ファイルとして生成し、タグは画像内へ埋め込まずテキストで出力します。

## ChatGPTでの利用

Skillsの作成・アップロード画面から、このZIPファイルをアップロードしてください。インストール後は、スキルを明示選択するか、参照画像とともにキャラクターリファレンス作成を依頼します。

## Codexでのローカル利用

展開した `ai-character-reference-reconstructor` フォルダを、次のいずれかへ配置します。

- リポジトリ用: `.agents/skills/`
- ユーザー共通: `$HOME/.agents/skills/`

## 主な設計方針

- 1枚へ情報を詰め込まず、目的別の独立画像に分離
- 見えない箇所を元デザインの複雑さに合わせて保守的に補完
- 第1画像で確定した構造を以後の正本として固定
- 左右非対称を単純反転しない
- 第4画像は必要な場合だけ生成
- 英語タグはコピー可能なテキストとして分離
