# AI Character Reference Reconstructor

現在の依頼に添付されたキャラクター画像だけを絶対的な視覚正本とし、画像生成AI、i2i、AI動画、複数モデル間で同一性を維持しやすい実用的な基準画像群へ再構築する。

## 参照情報を隔離する

- 現在の依頼に添付されたキャラクター画像だけを視覚資料として使用する。
- 保存済み画像、ローカルやプロジェクト内の画像、過去の会話、記憶、既存キャラクター設定、インターネット上の画像を参照しない。
- 画像入力をツールへ渡すときも、現在の添付画像と、このタスク内で生成した正本画像だけを明示的に選ぶ。無関係な過去画像を含む広い会話画像コンテキストを渡さない。
- 現在の依頼に添付されたすべての参照画像を生成前に確認し、同一キャラクターの相互補完資料として扱う。
- 参照間に差異がある場合は、最も明瞭かつ一貫して確認できる特徴を優先する。無作為に平均化したり、異なる要素を混ぜた新デザインを作ったりしない。
- ユーザーの現在の指示は対象人物や各添付画像の用途を特定するために使ってよいが、参照画像に見える造形を美化、簡略化、再設計、別衣装化しない。
- 使用可能なキャラクター画像が添付されていない場合だけ、生成開始前に添付を求める。生成開始後は途中確認を求めず、必要な全成果物を完成させる。

## 出力契約

次の画像を、1枚へ統合せず、独立した高解像度画像として順番に生成する。

1. `character_reference_01_fullbody_four_directions.png`
   - FRONT / LEFT / BACK / RIGHT
2. `character_reference_02_head_six_directions.png`
   - 上段: FRONT / 3/4 LEFT / 3/4 RIGHT
   - 下段: LEFT / RIGHT / BACK
3. `character_reference_03_six_expressions.png`
   - 上段: SOFT SMILE / JOY / ANGER
   - 下段: SADNESS / SURPRISE / FEAR
4. `character_reference_04_key_parts_details.png`
   - 第1〜第3画像だけでは重要構造を明瞭に定義できない場合だけ生成する。

画像生成機能が1回につき1枚だけ生成できる場合も、第1画像で止めず、第2画像、第3画像、必要なら第4画像まで別々に生成する。画像内へタグ辞書や統合タグ列を埋め込まない。

画像完成後、コピー可能なテキストとして次を出力する。

1. `English Prompt Tag Dictionary`
2. `Integrated Tag String`

## 生成前に正本を固定する

内部で次を分析し、正本台帳として固定する。長い分析文をユーザーへ表示しない。

- 顔の輪郭と、目、鼻、口、眉の形状・位置関係
- 頭部・後頭部・耳・角の形状
- 前髪、横髪、後ろ髪、分け目、毛先、髪飾り
- 髪色、瞳色、肌色
- 体格、頭身、肩幅、胴体、手足の比率
- 衣装の構造、丈、重なり、素材、模様、装飾
- 靴、手袋、装備、携行品
- 正面、側面、背面の接続構造
- 左右非対称と、キャラクター自身から見た正しい側
- 固有の識別特徴、装飾密度、モチーフ、デザイン言語
- 参照本来の描画方式
- 見えないため推論補完する箇所
- 第4画像が必要か

ビュー名の `LEFT` / `RIGHT` はキャラクターが画像内で向く方向を表す。非対称位置は必ず `character's left` / `character's right` で管理し、ビュー名と混同しない。

## 不足部分を限定的に補完する

- バストアップ、上半身、膝上の参照でも全身シートを省略しない。
- 見えている形状、体格、素材、配色、装飾密度、モチーフ、デザイン言語から自然に連続する構造だけを補完する。
- 複数の解釈が可能なら、単純さではなく参照画像全体との視覚的整合性が最も高い解釈を選ぶ。
- 見えている部分を推論で変更、省略、簡略化、再設計しない。
- 根拠のない模様、装飾、装備、アクセサリーを追加しない。
- 第1画像で確定した補完構造を、後続画像とタグ辞書の正本として固定する。
- 元参照画像で確認できる部分と生成済み画像が食い違う場合は、元参照画像を優先し、問題のある生成画像だけを修正する。

## 順番に生成する

詳細レイアウトと各シートの完成プロンプト骨格は、生成前に `references/sheet-specifications.md` を全文読む。

1. 元参照画像から第1画像を生成し、全身、衣装、背面、左右非対称、補完部分の正本とする。
2. 元参照画像と第1画像を使って第2画像を生成する。第2画像のFRONT無表情を顔の正本とする。
3. 元参照画像、第1画像、第2画像のFRONT正本を使って第3画像を生成し、表情だけを変える。
4. 第1〜第3画像では潰れる重要構造がある場合だけ、元参照画像と確定済み正本から第4画像を生成する。
5. 元参照画像と最終的な正本画像群からタグ辞書と統合タグ列を作る。

すべての画像、ビュー、表情で、同一人物、顔、頭部、髪、体格、頭身、衣装、装備、配色、素材、非対称、描画方式、補完デザインを維持する。単純反転で側面や非対称パーツを作らない。

## 共通レイアウトを固定する

- 背景を無地の非常に薄いニュートラルグレーにする。
- 均一で柔らかい照明を使い、本来の形状と色を明瞭にする。
- 正投影に近い自然な視点を使う。
- 広角、魚眼、強い遠近感、俯瞰、煽り、被写界深度、ドラマチックな陰影、逆光、色付き照明を使わない。
- 各要素の下に、短い英語ラベルだけを小さな読みやすいサンセリフ体で置く。
- 隣接要素の間に、キャラクター輪郭より十分弱い細い薄灰色の区切り線を置く。二段構成では必要に応じて段間にも置く。
- 身体、頭部、髪、耳、衣装、装備が隣の要素、区切り線、画像端へ接触しない余白を確保する。
- シート全体のタイトル、キャラクター名、説明文、台詞、矢印、寸法線、身長表記、カラーチップ、装飾枠、ロゴ、透かし、背景シーン、小物を追加しない。
- 参照本来の描画方式を維持し、アニメを実写・3DCG・コスプレ・フィギュア・ドールなどへ変換しない。
- 過剰な光沢、粒子、テクスチャ、エフェクト、色調補正を追加しない。

## 第4画像の必要性を判定する

次のような重要構造が通常の3枚では再現しにくい場合だけ生成する。

- 複雑な髪飾り、装身具、特殊な耳、角
- 翼、尻尾、武器、携行品
- 固有の留め具、模様、機械関節、可動構造
- 表裏で異なるパーツ
- 小さいが重要な左右非対称・識別パーツ

必要なパーツだけを重複なく大きく示し、形状、配色、素材、表裏、接続方向、装着位置が分かる最小限の角度を使う。全身像や表情で枠を埋めず、カラーチップも追加しない。通常の人型で3枚から十分に定義できるなら生成しない。

## タグを作成する

画像完成後に `references/tag-taxonomy.md` を全文読み、固定カテゴリと除外規則に従う。

- 元参照画像と完成した正本画像群で確認できる恒常的な視覚特徴だけを書く。
- 見えなかった部分は、第1画像で確定した補完デザインを記述する。
- 固有名詞、性格、職業、物語、能力、出身、世界観、関係性を推測しない。
- 表情、ポーズ、動作、構図、カメラ、背景、照明、画風、画質、レンダリング、一時状態を含めない。
- 画像から十分に判断できる色だけ、一般的な英語色名へ信頼できるHEX値を併記する。不確かなHEX値を作らない。
- 統合タグ列へ辞書にない情報を追加しない。

## 最終提示

次の順で提示する。

1. 第1画像
2. 第2画像
3. 第3画像
4. 必要な場合だけ第4画像
5. 英語タグ辞書
6. 統合タグ列

テキスト部分は次の形式にする。

````markdown
## 1. English Prompt Tag Dictionary

```text
IDENTITY:
...
ASYMMETRY:
...
```

## 2. Integrated Tag String

```text
...
```
````

第4画像を作らなかった場合は、「第4画像は不要と判断」とだけ短く記す。長い制作解説を付けない。

画像生成機能が利用できない場合は、生成済みだと装わない。代わりに、各画像を個別生成するための完成プロンプトを3本または4本と、英語タグ辞書、統合タグ列を出力する。

呼び出し例が必要な場合だけ `references/usage-examples.md` を読み、通常の生成では読み込まない。

## 品質を確認する

最終提示前に `references/quality-gate.md` を全文読み、すべて確認する。重大な不一致があれば、成果物全体ではなく問題のある画像またはテキストだけを修正し、再確認する。
