# Quality Gate

最終提示前にすべて確認する。重大な不一致があれば、問題のある画像またはテキストだけを修正し、もう一度このゲートを通す。

## 参照情報

- [ ] 現在の依頼に添付されたすべてのキャラクター画像を生成前に確認した
- [ ] 視覚資料は現在の添付画像と、このタスク内で生成した正本画像だけである
- [ ] 保存画像、過去の会話画像、記憶、既存キャラクター設定、インターネット画像を混ぜていない
- [ ] 参照間の差異は最も明瞭かつ一貫した特徴で解決し、無作為な平均や新しい混合デザインを作っていない
- [ ] 元参照で確認できる部分と生成画像が食い違う場合、元参照を優先した

## 成果物構成

- [ ] 第1〜第3画像を順番に生成し、それぞれ独立ファイルにした
- [ ] 画像生成が1回1枚でも、第1画像で止まらず第3画像まで完成させた
- [ ] 第4画像は必要性がある場合だけ独立ファイルとして生成した
- [ ] 複数シートを1枚の総合画像やコラージュへ統合していない
- [ ] 各画像は細部が潰れない実用的な高解像度である
- [ ] タグ辞書と統合タグ列を画像へ描き込んでいない
- [ ] 最終提示順が第1、第2、第3、必要時のみ第4、辞書、統合タグ列である

## 全画像の同一性

- [ ] すべて同じ人物、顔、頭部、髪型、体格、頭身に見える
- [ ] 衣装、装備、配色、素材、左右非対称構造が全画像で一致する
- [ ] 参照画像本来の描画方式を維持し、別画風、3DCG、実写、コスプレ、フィギュア、ドールへ変換していない
- [ ] 参照で確認できる造形を美化、変更、省略、簡略化、再設計、別衣装化していない
- [ ] 推論補完を見えない部分に限定し、根拠のない模様、装飾、装備、アクセサリーを追加していない
- [ ] 第1画像で確定した補完形状、配色、素材、装飾、左右配置を後続画像で固定した
- [ ] 左右非対称が反転、消失、増殖していない
- [ ] 隣接する人物・パーツ同士が融合していない

## 共通レイアウト

- [ ] 背景が無地の非常に薄いニュートラルグレーである
- [ ] 照明が均一で柔らかく、本来の形状と色が明瞭である
- [ ] 視点が正投影に近く、広角、魚眼、強い遠近感、俯瞰、煽り、被写界深度がない
- [ ] 各要素の下に短い英語ラベルだけを小さなサンセリフ体で配置した
- [ ] ラベルが内容と一致し、キャラクターより目立たない
- [ ] 隣接要素の間に細く薄い灰色の区切り線があり、キャラクター輪郭より弱い
- [ ] 十分な余白があり、身体、頭部、髪、耳、衣装、装備が画像端、隣接要素、区切り線へ接触していない
- [ ] シートタイトル、キャラクター名、説明、台詞、矢印、寸法線、身長、カラーチップ、装飾枠、ロゴ、透かし、背景小物がない
- [ ] ドラマチックな陰影、逆光、色付き照明、強い環境光、過剰な光沢、粒子、エフェクト、色調補正がない

## 第1画像

- [ ] 1行4列で左から FRONT / LEFT / BACK / RIGHT が各1体だけある
- [ ] FRONTは正面、LEFTは画像左向き側面、BACKは完全背面、RIGHTは画像右向き側面である
- [ ] 4体の縮尺、頭身、高さ、頭頂、顎、肩、腰、膝、足元が対応する
- [ ] 全身が頭頂から靴底まで欠けていない
- [ ] 全員が自然な直立姿勢で、腕を身体から少し離し、脚を平行にしている
- [ ] 腕組み、腰へ置く手、ひねり、曲げ脚、交差脚、振り返り、なびき、ポーズ差がない
- [ ] 正面・側面・背面で髪の長さ、衣装丈、身体比率、装備位置が一致する
- [ ] 背面の髪、衣装、留め具、装備の接続が物理的に成立する
- [ ] LEFTとRIGHTを単純反転していない

## 第2画像

- [ ] 2行3列で上段 FRONT / 3/4 LEFT / 3/4 RIGHT、下段 LEFT / RIGHT / BACK である
- [ ] 各方向がラベルどおりで、斜め方向は画像左右へ約45度である
- [ ] 全枠が肩上または胸上の同一範囲で、頭部サイズ、目の高さ、カメラ距離、間隔が揃う
- [ ] 全枠が閉じた口のニュートラルな無表情である
- [ ] 輪郭、目、鼻、口、顎、耳、頭蓋、髪、装飾が角度間で一貫する
- [ ] 横顔と斜め顔が別人化していない
- [ ] 後頭部、前髪、横髪、後ろ髪、頭部アクセサリーの接続と奥行きが明瞭である
- [ ] 衣装が首元・肩周辺だけに留まり、顔と髪より目立たない
- [ ] 左右を単純反転せず、非対称が正しい側にある
- [ ] 第1画像と矛盾せず、FRONT無表情を顔の正本として使える

## 第3画像

- [ ] 2行3列で上段 SOFT SMILE / JOY / ANGER、下段 SADNESS / SURPRISE / FEAR である
- [ ] 全枠が正面の肩上または胸上で、頭部サイズ、顔角度、目の高さ、カメラ、照明、衣装範囲が揃う
- [ ] 第2画像FRONTの顔、髪、装飾、衣装を維持し、表情だけを変えた
- [ ] 無表情の重複がなく、指定6表情が明確に区別できる
- [ ] SOFT SMILEは閉じた口の穏やかな微笑みである
- [ ] JOYは自然に口を開いた明るい笑顔である
- [ ] ANGERに過剰な赤面、歯の強調、怒り記号がない
- [ ] SADNESSに涙、鼻水、過剰な赤みがない
- [ ] SURPRISEが自然な驚き、FEARが目元と口元に緊張を持つ恐怖として異なる
- [ ] 汗、涙、集中線、効果線、台詞、背景演出、小物、手のポーズがない
- [ ] 表情によって別人化していない

## 第4画像

- [ ] 第1〜第3画像だけでは重要構造が明瞭にならないという生成理由がある
- [ ] 必要なパーツだけを重複なく大きく表示した
- [ ] 形状、配色、素材、表裏、接続方向、装着位置、左右差を理解できる
- [ ] 最小限の角度だけを使い、全身像、表情、ポーズ、世界観、カラーチップで枠を埋めていない
- [ ] 短い英語パーツラベル以外の不要な文字がない

## 英語タグ辞書

- [ ] 固定11カテゴリを指定順で出力し、カテゴリを追加・改名・省略していない
- [ ] 元参照画像と確定済み正本画像群の恒常的な視覚特徴だけを記述した
- [ ] 見えなかった部分は第1画像で確定した補完デザインと一致する
- [ ] 左右非対称を character's left / character's right で記述し、左右対称なら none とした
- [ ] 一般的な英語色名を使い、HEXは色を信頼して判断できる場合だけ併記した
- [ ] 同義語、重複語、識別力の低い評価語・品質語を過剰に含めていない
- [ ] 固有名詞、性格、職業、物語、能力、出身、世界観、関係性を推測していない
- [ ] 表情、ポーズ、動作、構図、カメラ、背景、照明、画風、画質、レンダリング、一時状態を含めていない

## 統合タグ列

- [ ] 1本のカンマ区切り英語タグ列を1つのコードブロックにした
- [ ] identity、face、hair、eyes、body、outfit、footwear、accessories、distinguishing features、asymmetry の順である
- [ ] タグ辞書にない情報を追加していない
- [ ] 六表情、ポーズ、動作、構図、背景、照明、画風、画質、レンダリングを含めていない
- [ ] snake_caseではなく自然な英語句を使い、重複を除いた
