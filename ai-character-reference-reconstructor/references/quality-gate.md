# Quality Gate

最終提示前に以下を確認する。重大項目に失敗した場合は再生成する。

## 全体

- [ ] 第1〜第3画像が別ファイルになっている
- [ ] 第4画像は必要性がある場合だけ生成されている
- [ ] 一つの総合シートへ統合されていない
- [ ] タグ辞書と統合タグ列が画像内にない
- [ ] 参照画像と同じキャラクターとして認識できる
- [ ] 画風が無断で変更されていない
- [ ] すべての重要配色が一致する
- [ ] 画像ごとに顔、髪型、衣装が変化していない

## 第1画像

- [ ] FRONT / LEFT / BACK / RIGHT が各1体だけある
- [ ] 4体の縮尺、頭身、接地線が一致する
- [ ] 全身が切れていない
- [ ] 腕と脚が交差していない
- [ ] 背面構造が物理的に成立する
- [ ] 左右非対称が反転事故を起こしていない
- [ ] 余計なポーズ差、表情差、衣装差がない

## 第2画像

- [ ] 6方向が揃っている
- [ ] すべて無表情
- [ ] 同じ顔、同じ頭部サイズ、同じ表示範囲
- [ ] 横顔と斜め顔が別人化していない
- [ ] 後頭部と髪の接続が明確
- [ ] 左右アクセサリーが正しい

## 第3画像

- [ ] 指定6表情が重複なく揃っている
- [ ] 表情以外が変化していない
- [ ] SURPRISEとFEARが明確に異なる
- [ ] 顔や頭部アクセサリーが第2画像と一致する
- [ ] カメラ位置とクロップが一定

## 第4画像

- [ ] 詳細化する必然性がある
- [ ] 重要パーツだけを大きく表示している
- [ ] 取り付け位置、表裏、左右差が理解できる
- [ ] 枠埋め用の不要な再掲がない

## テキスト

- [ ] 英語タグ辞書がカテゴリ別に整理されている
- [ ] 統合タグ列が1本のカンマ区切り文字列になっている
- [ ] 画像内ではなくコピー可能なテキストである
- [ ] 左右非対称が character-left / character-right で記述されている
- [ ] 未確認事項を断定していない
- [ ] 同義語や重複タグが過剰でない
