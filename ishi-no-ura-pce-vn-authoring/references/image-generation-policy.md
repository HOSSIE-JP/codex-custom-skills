# イベントスチル用プロンプト作成・人間受け渡しポリシー

この文書は `ishi-no-ura-pce-vn-authoring` のイベントスチル工程に対する最優先ポリシーです。
他の資料に異なる記述が残っている場合は、この文書と `SKILL.md` の規則を優先します。

## このスキルが担当する範囲

このスキルはイベントスチル画像を生成しません。
担当範囲は、承認済みシナリオ設計から、**人間がChatGPT Imageへそのまま渡せる確定プロンプトパックを作るところまで**です。

スキルが行うこと:

- 画像にするsceneと瞬間を選定する
- asset IDと使用sceneを決める
- 登場人物、構図、表情、ポーズ、小物、背景を整理する
- 人間が添付する参照画像を列挙する
- ChatGPT Imageへコピー＆ペーストできる自己完結したプロンプトを1枚ごとに作る
- 人間向けの生成、選定、PCE Game Editor登録手順を付ける
- 人間が結果画像を提示した場合、問題点を説明して再生成用の修正プロンプトを作る

スキルが行わないこと:

- ChatGPT Image、`image_gen`、その他の画像生成ツールの実行
- 画像ファイルの作成、編集、合成、クロップ、リサイズ、減色
- 人間に代わって画像を選定、保存、PCE Game Editorへ登録すること
- 未生成画像を完成スチルとして扱うこと

## 人間が担当する範囲

1. 指定された参照画像をChatGPT Imageへ添付する
2. スキルが作ったプロンプトを貼り付けて実行する
3. 生成結果を確認し、採用または再生成する
4. 必要なら生成結果をスキルへ提示し、修正プロンプトを受け取る
5. 採用画像をPCE Game EditorのImage画面へ取り込む
6. 224×136へ調整し、PCE向け減色・パレット生成を行う
7. `epNN_XXX` のbackground assetとして登録する
8. 更新後の `pce-assets.json` をスキルへ戻す

## プロンプトパックの必須項目

イベントスチル1枚につき、次を必ず含めます。

| 項目 | 内容 |
| --- | --- |
| asset ID | `epNN_001` など |
| 使用scene | `epNN_05_topic_still` など |
| 物語上の役割 | 題材提示、逆転、オチなど |
| 一瞬の定義 | どの動作・表情の瞬間を描くか |
| 参照画像 | 添付するファイル名、人物名、参照目的 |
| 完成プロンプト | ChatGPT Imageへそのまま貼れる本文 |
| 安全領域 | 28:17クロップで切ってはいけない人物・小物 |
| 禁止事項 | 文字、UI、別衣装、写実、3D調など |
| 推奨ファイル名 | `assets/images/epNN_001.png` |
| 登録情報 | ID、表示名、kind、使用scene |
| 受け入れチェック | 人物同一性、場面、手、小物、安全領域、文字禁止など |
| 再生成用雛形 | 問題箇所だけを直す修正プロンプト |
| 状態 | `PROMPT_READY / IMAGE_PENDING_HUMAN` |

## 自己完結したプロンプト

プロンプトは、別のChatGPT Image会話へ単独で貼っても意味が通る内容にします。

避ける記述:

- `承認済み設計のとおりに描いてください`
- `前と同じキャラクターで`
- `例の部室を使ってください`
- `上記のnegative promptを適用`

必要な情報はすべてプロンプト内へ書き直します。

プロンプト内で明記するもの:

- 作品名とイベントスチル用途
- 添付画像A、B、Cが誰の参照か
- 人物ごとの位置、向き、視線、手、姿勢、表情
- 重要な小物と、誰がどう触れているか
- 背景とカメラ距離
- 224:136、28:17の横長クロップ前提
- 太い輪郭、ベタ塗り、2〜3段階のセル影、大きな色面
- PCE低色数変換を見越した明快なシルエット
- 文字、字幕、数字、ロゴ、吹き出し、ゲームUI、透かしの禁止
- 参照画像と異なる髪型、服装、年齢感、体格の禁止
- コラージュ、設定画、複数案を並べることの禁止

## 標準プロンプト形式

```text
「いしのうらにいる！？」のゲーム用イベントスチルを1枚生成してください。
1枚の完成イラストだけを出し、設定画、比較案、コラージュにはしないでください。

添付参照画像:
- 画像A: [人物名]。髪型、髪色、顔立ち、制服、配色、年齢感、体格の正本
- 画像B: [人物名]。同上
- 画像C: [背景または小物]。必要な場合のみ

描く瞬間:
[何が起きた直後／最中かを1〜3文で具体的に書く]

構図:
[カメラ距離、人物配置、前後関係、視線、手、ポーズ、小物を書く]

各人物の表情:
- [人物名]: [感情と、その理由]
- [人物名]: [感情と、その理由]

背景:
[部室、廊下、学校など。不要な情報を増やさない]

画面仕様:
- 224:136、28:17へ後で安全にクロップできる横長構図
- 重要な顔、手、小物を中央寄りの安全領域へ収める
- 日本のアニメのセル画風
- 太く明快な輪郭線
- ベタ塗り中心
- 影は2〜3段階
- 大きな色面と高いコントラスト
- PCEの低色数変換後にも人物と小物が判別できる

参照一致:
- 添付画像と髪型、髪色、顔立ち、制服、配色、年齢感、体格を一致させる
- 指定した表情とポーズだけを場面に合わせて変える

禁止:
- 文字、数字、字幕、ロゴ、吹き出し、ゲームUI、枠、ウォーターマーク
- 写真風、写実、3Dレンダー風、油彩、水彩、厚塗り
- 広いエアブラシグラデーション、過剰な光沢、細かなノイズ
- 参照画像にない衣装変更、髪型変更、年齢変更、体格変更
- 重要な顔、手、小物が画面端で切れる構図
- コラージュ、複数案、設定資料風レイアウト

完成したイベントスチル1枚だけを生成してください。
```

## 修正プロンプト

人間が生成結果をスキルへ提示した場合、問題箇所を限定した修正プロンプトを作れます。
元プロンプトを曖昧に全面変更せず、次の形式を使います。

```text
添付した直前の生成画像を基準に再生成してください。
構図と画風は維持し、次の点だけを修正してください。

- [人物名]の[髪型／腕／表情／体格]を添付参照画像へ合わせる
- [小物]を[位置／大きさ／持ち方]へ直す
- 28:17クロップで切れないよう[人物／小物]を少し中央へ寄せる

変更しない点:
- [維持する構図]
- [維持する表情]
- [維持する背景]

文字、字幕、ロゴ、UI、ウォーターマークは入れないでください。
完成画像1枚だけを生成してください。
```

この修正プロンプトも、人間が別途ChatGPT Imageで実行します。スキル自身は実行しません。

## Pythonと画像ツールの禁止

このスキル内の画像工程では、次を使用しません。

- Python
- Pillow
- OpenCV
- matplotlib
- NumPyを使った画像配列処理
- SVG生成
- HTML canvas
- procedural art
- 画像生成ツールまたは画像編集ツール

禁止対象:

- 画像生成
- 切り貼り、合成、レイヤー化
- クロップ、リサイズ、回転、変形、余白追加
- 減色、パレット化、ディザ、色補正、輪郭強調
- 差分作成、修復、描き足し、消去
- コンタクトシート作成
- 画像ファイルを読み込む自動検査

JSON、テキスト、分岐到達性、文字数、manifest参照だけを扱うvalidatorは利用できます。

## 状態管理

工程の状態は次のいずれかで明示します。

- `PROMPT_READY`: 完成プロンプト、参照画像一覧、安全領域、受け入れ項目が揃った
- `IMAGE_PENDING_HUMAN`: 人間によるChatGPT Image実行待ち
- `IMAGE_PROVIDED`: 人間が生成画像を提示した
- `PCE_REGISTERED`: 人間がPCE Game Editorへ登録し、manifestを提供した
- `SCRIPT_INTEGRATED`: 登録済みassetをJSONへ組み込み、到達性を検査した

プロンプトを作っただけの段階では `PROMPT_READY / IMAGE_PENDING_HUMAN` です。画像生成または登録が完了したとは報告しません。
