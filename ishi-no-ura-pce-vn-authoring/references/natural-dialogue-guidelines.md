# 自然な会話を設計・執筆するためのガイドライン

この文書は「いしのうらにいる！？」のシナリオ設計と台詞執筆で、説明文のような会話、不自然な抽象表現、人物像が入れ替わる台詞を防ぐための基準です。

## 基本原則

会話は、作者がテーマを説明するための文章ではありません。登場人物が、その場で見た物、起きた出来事、相手の言葉、自分の感情に反応しながら、欲しい結果を得ようとする行動です。

自然な会話は次の順で成立します。

1. 何かが起きる
2. まず感情か短い反応が出る
3. 人物が自分に都合のよい解釈をする
4. 相手が質問、反論、観察を返す
5. 現物や行動が解釈を崩す
6. 当事者が具体的な不利益や矛盾を自分の言葉で認める
7. 理屈を完全に解決せず、人物らしい言い訳や行動で終える

テーマはこの流れの下に置き、完成した標語としてキャラクターに読ませません。

## シナリオ設計時の会話設計カード

各sceneについて、次を埋めます。

| 項目 | 内容 |
| --- | --- |
| 直前の出来事 | この会話が始まる具体的な原因 |
| 開始感情 | 部長、チカ、レンが最初にどう感じているか |
| 表向きの目的 | その人物が今、相手から何を得たいか |
| 隠れた動機 | 認められたい、負けを隠したい、遊びたい等 |
| 最初の反応 | 説明より先に出る短い言葉や行動 |
| 会話運動 | 反応→主張→質問／反論→具体例→変化／オチ |
| 画面で見せる証拠 | 手、視線、コントローラー、箱、結果画面など |
| テーマの下地 | 作者だけが把握する抽象的な意味。台詞にはそのまま書かない |
| 終了感情 | scene末尾で各人物がどう変わったか |
| 次への接続 | 次sceneの発話を自然に生む未解決事項 |
| 危険な台詞 | 説教、論文調、知識越境、急な改心など |

## 台詞のつながり

### 直前の台詞へ反応する

各発話は、原則として次のいずれかです。

- 答える
- 否定する
- 聞き返す
- 言い換える
- 具体例を出す
- 話をそらす
- 相手の行動を指摘する
- 感情を示す

直前の内容を無視して別の論点を始める場合は、「話をそらした」と相手が気づける形にします。三人が順番に作者の説明を読む「並行独白」にしません。

### 質問と答えを対応させる

質問の直後には、答えか、答えたくない反応を置きます。

不自然:

> チカ「試合で勝つと何が変わるんですか？」  
> レン「ランクは努力の証なんや！」

自然:

> チカ「試合で勝つと何が変わるんですか？」  
> レン「うちのほうが強いって分かる」  
> チカ「意見まで正しくなるんですか？」

レンが質問の一部だけへ答えたため、チカが残った論点を追えます。

### 反応を説明より先に置く

負けた直後に理屈を語らせず、まず「えっ」「今の何や」「待って」などの反応を置きます。感情がないまま分析へ移ると、人物が作者の解説装置に見えます。

### 具体から抽象へ進む

教訓や一般論は、具体的な出来事の後にだけ置きます。

不自然:

> 「強さを身分にすると、自分の言葉を上位者へ渡すことになる」

自然な会話運動:

> チカ「負けた人は、勝つまで黙るんでしたよね」  
> レン「それは…」  
> チカ「では今は、部長に反対できないんですか？」  
> レン「負けるたび黙らなあかんのか」

抽象的な意味は同じでも、登場人物は目の前のルールと自分の立場を話しています。

## 書き言葉を口語へ直す

次の特徴がある文は、音読して直します。

- 「〜ということになる」「〜であるため」「〜において」が続く
- 名詞が三つ以上連なる
- 一文に主張、理由、結論が全部入る
- 比喩の意味を聞き手がその場で理解できない
- 誰が何を指しているか、主語を補わないと分からない
- 相手が返事を挟めない長さになっている

修正例:

| 不自然 | 自然 |
| --- | --- |
| 経験は補正じゃなくて経験かな | 補正というより、積み重ねかな |
| ゲームの外まで勝ちました | 試合で勝つと、意見まで正しいことになるんですか？ |
| もっと強い人へ自分の言葉を渡すことになる | もっと強い人が来るたび、何を言うにも許可が要ることになる |
| 技術的優位性が発言権に波及しています | 強い人の言うことなら、全部正しいんですか？ |

この表の自然な台詞を毎話そのまま再利用せず、同じ変換原則を使います。

## キャラクター別の自然さ

### 部長

- まず観察や質問から入る
- 断言より「〜かな」「〜だね」を使う
- 原則として1〜2メッセージごとに相手の反応を入れる
- 知識を話すと長くなるが、途中でチカやレンに止められる
- 正論を言う場合も、勝者として説教しない
- 抽象論より、手元の機材、昔の操作、今の試合を例にする
- 最後は偏愛、ロマン、周辺機器などへ少し脱線し、完全な先生役にしない

### チカ

- 知らない用語は知ったふりをせず質問する
- 結論を宣言するより「〜なんですか？」と関係を確認する
- 目、手、声の大きさ、机、箱など、見えている事実を指摘する
- 作者の教訓を代弁する抽象的な総括を避ける
- 同じ「つまり〜ということですね」を繰り返さない
- 丁寧語は保つが、論文のような語彙を使わない
- 矛盾の指摘は短く、本人が続きを言わざるを得ない余白を残す

### レン

- まず感情が出て、その後で理屈をつける
- 似非大阪弁は短い語尾や否定へ使い、全単語を方言化しない
- 一文を長くせず、「ちゃう」「待て」「せやけど」でテンポを作る
- 追い詰められたら、基準変更、言い換え、別名付けで逃げる
- 実力や努力は本物として扱い、単なる無知な悪役にしない
- 因果応報の後も、悔しさ、誇り、遊びたい気持ちを残す
- 急に全面謝罪させず、教え方や行動が少し変わる形で成長を見せる

## 感情の連続性

人物の感情は段階を踏みます。

例: レンが敗北を受け入れる場合

1. 驚く
2. 入力や仕様を疑う
3. 相手の経験を理由にする
4. 自分の論理を返される
5. 具体的な不利益に気づく
6. 完全降伏ではなく、行動を少し変える

「嘲笑していた次の台詞で反省する」「怒っていた直後に朗らかに教え始める」のような飛躍を避けます。間に視線、沈黙、言い訳、短い否定を置きます。

## 会話の長さとリズム

目安であり、機械的な絶対条件ではありません。

- 1メッセージは原則1つの発話行為
- 同一話者の連続は通常2メッセージまで
- 3メッセージ続く場合は、興奮した説明など理由を持たせ、直後に反応を入れる
- 3〜5メッセージごとに、驚き、質問、行動、視線などの変化を置く
- 同じ情報の言い換えは、感情が強まるかギャグが進む場合だけ使う
- 抽象的な原則は短くし、すぐ具体的な行動へ戻す
- ナレーションで人物の内面や教訓を説明しない

## シナリオ設計段階の自然さ監査

台詞全文を書く前に、各sceneへ次の問いを当てます。

1. 最初の台詞は、直前の出来事がなくても言えてしまわないか
2. 各人物は今、相手から何を得ようとしているか
3. 直前の発話へ誰も反応しない箇所がないか
4. 質問に答えず別の説明へ逃げていないか。逃げるなら意図が見えるか
5. チカが知らない知識や作者の結論を代弁していないか
6. 部長が常に最終回答を与える教師になっていないか
7. レンの主張に、本人なりの努力や欲望があるか
8. テーマを台詞から削っても、出来事と行動で意味が残るか
9. 感情が一段飛ばしで変わっていないか
10. 次sceneへ移る理由が会話内にあるか

## 台詞完成後の三つのテスト

### 音読テスト

声に出し、助詞の重なり、長い修飾、息継ぎできない文、口にしない書き言葉を直します。

### 話者入れ替えテスト

部長、チカ、レンの誰が言っても成立する台詞は、語彙、目的、知識、感情を話者固有にします。

### 聞き手テスト

各台詞について「聞き手は何に反応して次を言うのか」を答えられない場合、順番を直すか、反応を一つ足します。

## PCE向け分割

自然な文を先に完成させてから画面用に分けます。

- 文節や息継ぎで改行する
- 助詞だけを次行へ送らない
- 主語と述語を遠くへ分けない
- 17文字へ収めるために不自然な同義語へ変えない
- 一つの自然な発話が長い場合は、意味の区切りで複数messageへ分ける
- 分割後も次のmessageが同じ話者の続きだと自然に分かるようにする
