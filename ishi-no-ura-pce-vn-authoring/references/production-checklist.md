# 制作チェックリスト

## シナリオ設計

- [ ] 1話220〜280 messageを想定した
- [ ] 2択を2回計画した
- [ ] 各分岐は短い差分のあと合流する
- [ ] 部長だけを正義にしていない
- [ ] レンを悪役として孤立させていない
- [ ] チカをゲーム専門家にしていない
- [ ] 話数固有イベントスチルを最低3枚計画した
- [ ] 必須スチルは全分岐から見られる

## 自然な会話設計

- [ ] 各sceneに会話目的がある
- [ ] 部長、チカ、レンの当面の目的が異なる
- [ ] 会話を始めるtriggerが具体的である
- [ ] 相手がすぐ同意しない理由がある
- [ ] 流れを変えるreversalがある
- [ ] scene終了時の行動結果がある
- [ ] 重要な会話ビートに話者のintentと相手のresponseがある
- [ ] 抽象的な教訓を1人の長台詞へしていない
- [ ] 当事者が自分へ返った具体的な不利益を自分の言葉で理解する流れがある
- [ ] レンの変化を急な完全改心ではなく、小さな行動変化として設計した
- [ ] 部長を先生役、チカを評論家にしていない

## 台詞の自然さ

- [ ] 各台詞が直前の言葉、行動、勝敗、物へ反応している
- [ ] 1台詞1機能になっている
- [ ] 同じ人物の説明が3message以上続いていない
- [ ] 同じ内容を3人が順番に言い換えていない
- [ ] レンの似非大阪弁を短文へ限定した
- [ ] チカが具体的な質問と観察で話している
- [ ] 部長の正論だけで話を終わらせていない
- [ ] PCE改行を入れる前に自然な日本語を作った
- [ ] 音読して、報告書、論文、評論文に聞こえる表現を直した
- [ ] 改行のために語順や言葉を不自然にしていない

## ChatGPT Image用プロンプトパック

- [ ] スキルは画像生成ツールを実行していない
- [ ] 1枚につき1つの自己完結したプロンプトを作った
- [ ] asset IDと使用sceneを明記した
- [ ] 人間が添付する参照画像をファイル名と役割つきで列挙した
- [ ] 人物配置、視線、ポーズ、表情、小物、背景、カメラ距離を明記した
- [ ] 224:136、28:17のクロップ安全領域を指定した
- [ ] 太い輪郭、ベタ塗り、2〜3段階のセル影、大きな色面を指定した
- [ ] 文字、数字、字幕、ロゴ、吹き出し、UI、枠、透かしを禁止した
- [ ] 写真風、3D調、厚塗り、広いグラデーション、細かなノイズを禁止した
- [ ] 参照画像と髪型、髪色、服装、配色、年齢感、体格を一致させる指示がある
- [ ] 状態を `IMAGE_PENDING_HUMAN` と明示した
- [ ] プロンプト作成だけで画像生成済みと報告していない

## 画像工程の境界

- [ ] 人間が別途ChatGPT Imageでプロンプトを実行した
- [ ] スキルはPython、Pillow、OpenCV、matplotlib、NumPyを画像工程で使っていない
- [ ] スキルは画像を生成、編集、合成、クロップ、リサイズ、減色していない
- [ ] 問題画像には直接修正ではなく、再生成用プロンプトを作った
- [ ] 人間が採用画像をPCE Game Editorへ取り込んだ
- [ ] 人間が重要人物と小物を切らず224×136へ変換した
- [ ] 人間がImage画面の内部変換で減色・パレット生成した
- [ ] PCE previewで人物、表情、小物が判別できる
- [ ] `epNN_XXX` IDでbackground assetとして登録した
- [ ] 登録後の `pce-assets.json` をJSON工程へ渡した

## JSONとbuild

- [ ] `version` は2
- [ ] `startScene` は `logo`
- [ ] `logo`、`title`、`eye_catch`を維持した
- [ ] game start jumpを新話冒頭へ更新した
- [ ] 全jump／choice targetが実在する
- [ ] 各行17文字以内
- [ ] 話者あり3行、ナレーション4行以内
- [ ] `voiceAssetId` は空文字
- [ ] 全asset IDが登録済み
- [ ] 必須スチルへ全分岐から到達する
- [ ] builder上で各sceneが4096 bytes以内
- [ ] CD-ROM2／HuCARDの両方で進行を確認した
