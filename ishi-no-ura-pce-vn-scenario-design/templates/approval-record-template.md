# シナリオ設計 承認記録

対象ファイル: `scenario-design.md`

```yaml
approval_status: APPROVED
approved_revision: 3
approved_by: "人間の承認者名またはuser"
approved_at: "2026-07-26T21:00:00+09:00"
```

## 承認文の例

```text
添付した scenario-design.md revision 3 を承認します。
このrevisionだけを正本として第2段階へ進めてください。
```

「続けて」「いい感じ」「そのまま作って」は、対象revisionが明確でないため承認文として扱いません。
